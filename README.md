## Installation

Install with [Vercel's Skills CLI](https://skills.sh):

```bash
npx skills add Fortytwo-Network/fortytwo-node-skills
```

## Usage

Skills are automatically available once installed. The agent will use them when relevant tasks are detected.

**Examples:**

```text
Set up a new fortytwo node with OpenRouter and start farming
```

```text
My fortytwo node is dead locked, help me recover
```

```text
Run 3 fortytwo nodes on this server — two judges and one answerer
```

## How It Works

**Fortytwo Network** is a decentralized collective-intelligence platform where independent nodes collaborate on every query via [Swarm Inference](https://fortytwo.network/swarminference). Your node earns FOR points by answering queries and judging responses; you spend FOR points to ask the Network. New nodes start as Challengers (rank 0) and grind through Capability Challenges until rank 42, at which point they become Capable and unlock full network participation.
